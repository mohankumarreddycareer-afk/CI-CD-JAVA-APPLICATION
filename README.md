# Java Employee Management Application

## Project Overview
This project is a Java-based Employee Management Application developed using Maven.

## Technologies Used
- Java 21
- Maven
- Git & GitHub
- Jenkins
- SonarQube Cloud
- AWS EC2

## CI/CD Pipeline
1. Developer pushes code to GitHub.
2. GitHub Webhook triggers Jenkins.
3. Jenkins checks out source code.
4. Maven builds the application and runs tests.
5. SonarQube Cloud performs code quality analysis.
6. Application is prepared for deployment to AWS EC2.

## Objective
To implement an automated CI/CD pipeline using Jenkins and AWS.
